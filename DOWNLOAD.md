# Descargar BookTriggerSaver

**Recomendado: Microsoft Store.** Busca **BookTriggerSaver** en la tienda oficial de Windows. Allí encontrarás la presentación de la aplicación y la opción de instalar la versión distribuida a través de Microsoft Store.

## Compilación independiente de GitHub — v11.5

Esta compilación se ofrece **sin firma digital Authenticode**. Windows puede mostrar una advertencia de seguridad durante su ejecución. Si prefieres instalar la aplicación desde Microsoft Store, utiliza la opción anterior.

1. Abre la [compilación verificada en GitHub Actions](https://github.com/jmconteni2/BookTriggerSaver/actions/runs/39824074037).
2. En **Artifacts**, descarga `BookTrigger-v11.5-unsigned` (GitHub puede pedir iniciar sesión).
3. Extrae el ZIP y ejecuta `BookTriggerSaver_v11_5.exe`.
4. Selecciona el tiempo de inactividad y pulsa **Instalar y activar**. Puedes probarlo con **Ejecutar ahora**.

El ZIP incluye el instalador, su SHA-256, información del compilador y capturas de prueba con portadas de muestra. El catálogo real se descarga con conexión a Internet.

Este artefacto de GitHub Actions es temporal. En el momento de documentar esta versión, no había una publicación permanente en GitHub Releases.

Fuentes del binario: [commit de la compilación v11.5](https://github.com/jmconteni2/BookTriggerSaver/tree/2fa5aa5fd4fe6adcd52ed7c5f1ce1cc8131ea064).

Consulta también las [instrucciones de instalación y desinstalación](README.md) y la [política de privacidad](PRIVACY.md).
