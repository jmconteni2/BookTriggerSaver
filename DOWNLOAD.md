# Descargar BookTriggerSaver

**[Instalar desde Microsoft Store](https://apps.microsoft.com/detail/9NBLC0ZVZ08P)** — Opción recomendada. Consulta imágenes, características y descarga la aplicación desde la tienda oficial de Windows.

## Descarga alternativa desde GitHub

También está disponible [BookTriggerSaver v11.5 (beta) en GitHub Releases](https://github.com/jmconteni2/BookTriggerSaver/releases/tag/v11.5), con el archivo `Instalador.Salvapantallas.BookTrigger.Beta.exe`.

Esta publicación se presenta como versión beta. Si Windows muestra un aviso sobre la reputación o firma del instalador, utiliza preferentemente la versión de Microsoft Store.

## Código fuente y compilación

El repositorio contiene código fuente y el script `Build.ps1` para compilar en Windows con Go 1.27.3. La [compilación automatizada v11.5](https://github.com/jmconteni2/BookTriggerSaver/actions/runs/39824074037) también está documentada, pero los artefactos de GitHub Actions pueden caducar; para descargar el instalador desde GitHub utiliza **Releases**.

Consulta [instalación y características](README.md) y [privacidad](PRIVACY.md).
