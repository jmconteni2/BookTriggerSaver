# Descargar BookTriggerSaver v11.5

Compilación candidata probada, **sin firma digital**.

1. Abre la [compilación verificada en GitHub Actions](https://github.com/jmconteni2/BookTriggerSaver/actions/runs/39824074037).
2. En **Artifacts**, descarga `BookTrigger-v11.5-unsigned` (GitHub puede pedir iniciar sesión).
3. Extrae el ZIP y ejecuta `BookTriggerSaver_v11_5.exe`.
4. Elige los minutos y pulsa **Instalar y activar**. Al finalizar puedes usar **Ejecutar ahora**.

El ZIP incluye el instalador, su SHA-256, información del compilador y capturas de prueba con portadas de muestra. El catálogo real se obtiene al ejecutar el salvapantallas con conexión. El artefacto de Actions es temporal; todavía no existe una publicación permanente en GitHub Releases.

Fuentes exactas del binario: [2fa5aa5fd4fe6adcd52ed7c5f1ce1cc8131ea064](https://github.com/jmconteni2/BookTriggerSaver/tree/2fa5aa5fd4fe6adcd52ed7c5f1ce1cc8131ea064).

La instalación y desinstalación se explican en [README](README.md). Consulta también [Privacidad](PRIVACY.md).
